# Translations (English only)

`en/*.tsv` holds the English text of the v3.1 patch: one file per game script CSV, one line per message cell.

- `row` is the 1-based row in the original CSV, and `column` is `message` or `short` (the shortened battle message).
- `\n` marks a line break inside a message box.
- **No game data:** no Japanese text, headers, IDs, event notes or comments. Those stay in the private source, which you rebuild from your own dump.
- Generated by `tools/extract_english.py`. 44,176 English cells across 286 files. Another 775 cells still contain Japanese; those are issue #4, for v4.

Translation by Carl (Muse). Reviewed and shipped by the BucketComps team.
