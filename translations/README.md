# Translations (English only)

`en/*.tsv` holds the English text of the v3.1 patch: one file per game script CSV, one header line, then one line per message cell.

- `row` is the 1-based row in the original CSV, and `column` is `message` or `short` (the shortened battle message).
- `\n` marks a line break inside a message box.
- **No game data:** no Japanese text, headers, IDs, event notes or comments. Those stay in the game's own files, which you extract from your own dump when you build (see `docs/PIPELINE.md`).
- Generated by `tools/extract_english.py`; `tools/merge_tsv.py` writes the text back into extracted CSVs. 44,172 English cells across 286 files (measured at this commit). The in-game text that is still Japanese is tracked in issue #4 for v4.
