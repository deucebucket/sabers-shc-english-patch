# Security and takedown contact

This project distributes no game files. If you believe something in this repository or a release should not be here (a security problem in the installers, private information, or a rights-holder concern), please [open an issue](../../issues/new/choose) and mark it clearly in the title. Issues are the project's only contact channel and are read by the maintainers. Rights-holder takedown requests are honoured promptly.
